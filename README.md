# SQL for Data Analysis

## Project Overview
This project focuses on analyzing an e-commerce sales dataset using SQL in MySQL Workbench. It involves exploring the data, filtering records, performing aggregations, and extracting useful business insights.

## Dataset
- Dataset: E-commerce Sales Data
- Records: 100
- Format: CSV
- Table: ecommerce_sales_data

## Tools Used
- MySQL Workbench
- MySQL
- SQL

## SQL Concepts Covered
1. Database and table exploration
2. SELECT statements
3. Filtering using WHERE
4. Sorting using ORDER BY
5. Aggregate functions (COUNT, SUM, AVG, MIN, MAX)
6. GROUP BY and HAVING
7. Joins (INNER JOIN, LEFT JOIN, RIGHT JOIN)
8. Subqueries
9. Views

## Analysis Performed
- Explored the e-commerce sales records.
- Analyzed product categories.
- Calculated total revenue and average product price.
- Identified high-priced products.
- Filtered customers based on age and gender.
- Analyzed sales by city and product category.
- Practiced joins and subqueries.
- Created a view for sales summary.

## Project Files
- `task3_ecommerce_analysis.sql` – SQL queries used for analysis.
- `ecommerce_sales_data.csv` – Dataset used in the project.
- `Screenshots/` – Query output screenshots.

## Conclusion
This project provided practical experience in SQL-based data analysis using MySQL Workbench. It helped develop skills in data exploration, data filtering, aggregation, joins, subqueries, and views.
